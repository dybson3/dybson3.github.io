O mnieAbout Me

Inżynier cyberbezpieczeństwa (Politechnika Wrocławska) z praktycznym doświadczeniem w zarządzaniu tożsamością i dostępem, reagowaniu na incydenty i wykrywaniu zagrożeń. Jako Junior Information Security Engineer w Armacell zarządzam IAM w Azure Entra ID, automatyzuję procesy bezpieczeństwa w PowerShellu i wspieram wdrożenie Zero Trust Network Access na infrastrukturze Fortinet. Analitycznie podchodzę do logów i ruchu sieciowego, wyłapując zagrożenia i anomalie. Mam certyfikat Microsoft SC-500 i coraz mocniej skupiam się na bezpieczeństwie chmury oraz architekturze bezpieczeństwa w Azure.

As a Junior Information Security Engineer at Armacell, I manage IAM in Azure Entra ID, automate security workflows with PowerShell, and support Zero Trust Network Access implementation on Fortinet infrastructure. I apply strong analytical thinking to identify security threats and anomalies across log and network data. Microsoft SC-500 certified, with a growing focus on cloud security and Azure-based security architecture.
